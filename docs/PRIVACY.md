# Daeroh privacy — development build

Daeroh is a private, unreleased Android downstream of Hermes Console. It does **not** use XPeta Lab's privacy policy as its own; [the upstream policy](PRIVACY_POLICY.md) describes the upstream app and developer, not Daeroh.

Current source sends conversation content and attachments to the Hermes server you configure; optional speech/model/catalog services can contact their selected providers. Connection credentials use Android secure storage. The inherited code includes microphone, camera, notifications, local files, and network features. Transport to DNS names requires HTTPS/WSS; cleartext is limited to literal private IP destinations.

An optional, self-hosted GlitchTip reliability collector can be configured only at build time. It is absent from builds without `DAEROH_DIAGNOSTICS_DSN`, defaults off, and cannot send until the person using the app opts in under Settings → Data. DSNs with a secret key are rejected. When active, it sends only a fixed source label (`flutter` or `platform`) and a truncated one-way stack-shape hash. The GlitchTip/Sentry envelope necessarily carries the fixed collector route, project public key, SDK name/version, protocol trace context (including a random trace ID), ephemeral event ID, and timestamp; it never includes a user-configured Hermes endpoint, exception text, prompts, messages, attachments, credentials, request data, user/device identifiers, breadcrumbs, or logs. The transport connects directly, accepts only that exact ingestion route, rejects redirects and proxies, and closes outstanding connections when the setting is turned off.

This is not product analytics, advertising, or tracking. It is a Daeroh-operated diagnostic service for a privately configured collector; it is not an XPeta Lab service. This statement is not a published release privacy policy; behavior and permissions still require on-device verification before any public distribution. Do not assume the upstream developer receives, supports, or maintains this downstream's data or releases.
